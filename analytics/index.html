Bos Kaos Social Analytics

Alat analisis internal untuk akun media sosial Bos Kaos yang dihubungkan dengan persetujuan pengelola berwenang.

Tujuan aplikasi

Mengolah statistik profil dan performa konten Instagram serta TikTok menjadi grafik, perbandingan periode, dan laporan mingguan atau bulanan. Sumber data dapat berupa API resmi yang diizinkan dan file ekspor yang diberikan pengelola.

Integrasi masih dalam tahap pengembangan dan pengujian. Halaman ini adalah informasi publik aplikasi, bukan dashboard statistik yang telah beroperasi.

Cakupan

Aplikasi dirancang untuk analisis, bukan untuk mengunggah, menghapus, atau menerbitkan konten dan bukan untuk membalas pesan. Pembacaan DM otomatis belum diaktifkan. Pencatatan lead saat ini direncanakan melalui input manual pengelola.

Dashboard dan data operasional ditujukan bagi pengelola yang berwenang. Data statistik privat dan kredensial tidak diterbitkan pada situs GitHub Pages ini.
